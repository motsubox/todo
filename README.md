# TODO

ブラウザだけで動くシンプルな TODO アプリです。ビルドや依存パッケージは不要です。

## 使い方

`index.html` をブラウザで開くだけで動きます。

## 機能

- タスクの追加（Enter または「追加」ボタン）
- 完了 / 未完了の切り替え、「すべて完了」で一括切り替え
- ダブルクリックで編集（Enter で確定、Esc でキャンセル、空にすると削除）
- タスクの削除、完了済みタスクの一括削除
- 「すべて / 未完了 / 完了」での絞り込み
- `localStorage` への自動保存（リロードしても消えません。別タブの変更も反映されます）
- ライト / ダークモード対応

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | 見た目 |
| `app.js` | 状態管理・描画・イベント処理 |
